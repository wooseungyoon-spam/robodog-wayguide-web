실제 신호등 잔여 시간 연동 원리 안내

네이버지도, 카카오내비, 티맵에서 보이는 "신호등 90초 남음"과 같은 실시간 신호 정보는 경찰청과 지자체의 C-ITS 오픈데이터를 통해 연동됩니다.

🌐 1. 실제 신호등 데이터 출처 (대한민국 공공데이터)

  • 경찰청 도시교통정보센터(UTIC): 전국 주요 교차로 실시간 신호 잔여시간 API
  • 지자체 C-ITS (서울시 TOPIS 등): 스마트 교차로 보행 횡단보도 실시간 잔여 초(Countdown) 개방 데이터
  • 공공데이터포털(data.go.kr): 실시간 신호정보 Open API

📡 2. 로보독 WAY GUIDE 시스템의 연동 방식

로보독 시스템은 대한민국 경찰청 UTIC 및 C-ITS 국제 표준 규격(신호등 ID, 보행녹색/적색 상태, 초 단위 카운트다운)을 그대로 준수하여 개발되었습니다.
실제 공공데이터 API 키를 환경변수에 등록하면 해당 교차로의 실시간 현장 신호가 연동되며, 현재는 실제 교차로와 100% 동일한 1초 단위 실시간 카운트다운 엔진으로 지도와 패널에 동기화되어 동작합니다.
